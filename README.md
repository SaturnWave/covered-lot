# Covered Lot

Covered Lot (working title) is a mobile puzzle game for Android and iOS.

This repository will hold the game's Unity client. The rules engine it uses lives in
[SaturnWave/puzzle-engine](https://github.com/SaturnWave/puzzle-engine) and is copied
into the Unity project as DLLs.

Status: pre-production. The Unity project arrives in a later phase of the development plan.
